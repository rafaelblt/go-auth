# Ed25519 rather than RSA or HMAC

- **Status:** Accepted
- **Date:** 2026-09-12
- **Areas:** authentication

## Context

Access tokens are verified by clients, outside this service, so the signing
algorithm decides what those clients must hold.

## Decision

Access tokens are signed with Ed25519. Its keys and signatures are far smaller
than RSA's and signing is faster, and JWKS support for `OKP` keys is standard.

## Alternatives considered

- **HMAC** — verification would require sharing the signing secret with every
  client, any of which could then mint tokens.
- **RSA** — larger keys and signatures, slower signing.

## Consequences

An RS256 implementation may still be worth adding for clients whose JWT library
predates Ed25519 support.
